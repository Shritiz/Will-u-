# ✨ Will-u- | Custom Web Experiences

## 🎯 About This Project

**Will-u-** is a portfolio of custom-built interactive websites and games. Each project is meticulously designed with attention to detail, smooth animations, elegant typography, and heartfelt messaging. From personalized birthday celebrations to fun interactive games, every experience is tailored to make moments memorable.

This collection showcases:
- **Custom Birthday Sites** - Multi-page interactive birthday experiences with animations, memories, and personalized messages
- **Interactive Games** - Engaging web-based games like Super Tic-Tac-Toe with responsive design
- **Question Pages** - Beautifully styled decision-making experiences with smooth interactions
- **Special Occasion Websites** - Personalized sites for any celebration or special event

## 💻 Getting Started

### Quick Start
1. Clone this repository
2. Navigate to any project folder
3. Open the `index.html` file in your browser
4. Explore the interactive experience!

### For Local Development
```bash
# No build process needed! Just open the HTML files
# For development server (optional):
python -m http.server 8000
# or
npx http-server
```
